# 93NorthStudio.com

**93North Studio** is a digital agency based in Northern Ireland, specializing in **web design, web development, and digital marketing**. This project is the official website for the agency, built to showcase services, portfolio, and contact options in a modern, interactive, and highly responsive design.

---

## Features

- Fully **responsive design** optimized for mobile, tablet, and desktop
- **GSAP animations** for smooth, dynamic page transitions
- **Next.js** for server-side rendering and performance
- **Firestore** integration for storing dynamic content or contact form submissions
- **Resend** email handling for contact form notifications
- **Tailwind CSS** for modern, utility-first styling
- SEO-friendly structure to enhance search engine visibility

---

## Tech Stack

- **Frontend & Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animation:** [GSAP](https://greensock.com/gsap/)
- **Database:** [Firestore](https://firebase.google.com/products/firestore)
- **Email Service:** [Resend](https://resend.com/)
